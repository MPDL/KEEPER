{% trans "Recommendation for Account Deactivation, Off-boarding and Data Retention" %}

{% blocktrans %}Keeper is a service intended for users within the Max Planck Society (MPG). To ensure continued access to research data and prevent loss of access when a user leaves an institute, a proper off-boarding process should be followed. {% endblocktrans %}

{% blocktrans %}The responsibility for off-boarding lies with the Keeper user itself.{% endblocktrans %}

{% blocktrans %}1. Users with Local Keeper Account Authentication{% endblocktrans %}

{% blocktrans %}Local Keeper accounts use email address and password authentication.{% endblocktrans %}

{% blocktrans %}When an employee leaves an MPI or their contract ends, it is recommended to complete the following steps before departure:{% endblocktrans %}

  • {% blocktrans %}Review the Keeper libraries and ownership.{% endblocktrans %}
  • {% blocktrans %}Transfer ownership of relevant libraries to an active Keeper user (recommended: Research Data Manager or Project/ Department Lead).{% endblocktrans %}
  • {% blocktrans %}Review and update sharing permissions.{% endblocktrans %}
  • {% blocktrans %}Ensure that important data is properly documented and retained.{% endblocktrans %}

{% blocktrans %}The user's MPG email account may be deactivated by the institute as part of its standard offboarding process. Since the email address is associated with the Keeper account, password recovery and future access may no longer be possible after the email account has been deactivated. To avoid losing access, we recommend notifying Keeper Support and completing any necessary ownership transfers before the employee's departure.{% endblocktrans %}

{% blocktrans %}Please note:{% endblocktrans %}

  • {% blocktrans %}Keeper accounts are not automatically deleted after a contract ends.{% endblocktrans %}
  • {% blocktrans %}Stored data remains available on the Keeper server.{% endblocktrans %}
  • {% blocktrans %}Access may be lost if ownership and access rights are not transferred before the account becomes inaccessible.{% endblocktrans %}

{% blocktrans %}2. Users with Keeper Accounts Using SSO Authentication{% endblocktrans %}

{% blocktrans %}For users accessing Keeper through MPG Single Sign-On (SSO), access is linked to their active MPG affiliation.{% endblocktrans %}

{% blocktrans %}When a contract ends and the MPG account is deactivated:{% endblocktrans %}

  • {% blocktrans %}SSO access to Keeper is automatically revoked.{% endblocktrans %}
  • {% blocktrans %}The user can no longer sign in using their institutional credentials.{% endblocktrans %}
  • {% blocktrans %}The Keeper account and its stored data are not deleted.{% endblocktrans %}

{% blocktrans %}Cared Data Certificate for Long-Term Data Archiving{% endblocktrans %}

{% blocktrans %}For projects that require long-term data archiving, Keeper offers the Cared Data Certificate (CDC). The CDC is unique to Keeper and acknowledges MPDL's commitment to store and archive your data for up to 10 years in accordance with the Cared Data Commitment.{% endblocktrans %}

{% blocktrans %}For details, please refer to the Cared Data Certificate article.{% endblocktrans %}

{% blocktrans %}To request the deactivation of a local Keeper account, please contact the Keeper Support team at keeper@mpdl.mpg.de.{% endblocktrans %}
