{% trans "Certify Keeper documents" %}

{% trans "In a nutshell" %}

  • {% blocktrans %}Anonymously (without exposing data) create a digital fingerprint of your file(s), which includes a unique identifier of the specific file, a timestamp, and optional metadata (anonymous/not exposed to the public) secured by a blockchain. Note: adding metadata will add your project to Keeper's project catalog - only visible to MPG users.{% endblocktrans %}
  • {% blocktrans %}No impact on your files & can be used at any time in your data life-cycle.{% endblocktrans %}
  • {% blocktrans %}Keeper stores the certificate(s) representing the digital fingerprint.{% endblocktrans %}
  • {% blocktrans %}Keeper also reconciles the certificate(s) with the specific file version you certified and give you easy access to both (as long as you don't delete the files).{% endblocktrans %}
  • {% blocktrans %}Prerequisite: you need to be the owner (in the Keeper sense) of the data.{% endblocktrans %}

{% trans "Why certify files?" %}

{% trans "A certified file has some useful properties:" %}

  • {% trans "The hash is unique to the exact file you've just certified and cannot be reproduced by anyone with any other file (or even another version of that specific file)." %}
  • {% blocktrans %}With the certificate or the transaction ID you've received, you can prove, that this specific file has been certified by you at the specific time. If you haven't separately stored the certified version, you can simply go to "Library Details" and find your certificates and files and download any of the files. Reconcile it with the previous transaction by using https://certify.bloxberg.org/verify and proof your initial certification.{% endblocktrans %}
  • {% trans "You can also use the feature to make sure you are using the exact version of a file you wanted to use. You've uploaded some raw data to be used months later? Certify the file now and before you want to use it. Both hashes will be the same and you can be certain it contains the same data - without only the slightest adjustment." %}
  • {% trans "Need to timestamp data? Then the certification is also suitable - just with much more features." %}
