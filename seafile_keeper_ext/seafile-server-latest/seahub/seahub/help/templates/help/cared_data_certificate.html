{% trans "Cared Data Certificate" %}

{% blocktrans %}Unique to Keeper is the Cared Data Certificate, a way to acknowledge to you our commitment to store and/or archive your data long term (10 years)*.{% endblocktrans %}

{% blocktrans %}The Cared Data Certificate (CDC) requires some data input from your side so we can personalize the CDC specially for you. It's also specific to one library and multiple CDCs can be generated in case you are using multiple libraries and would like to have the CDC for some or all of them.{% endblocktrans %}

{% blocktrans %}To get started, each new library comes with two automatically generated files, the archive-metadata.md and the Cared-Data-Certificate-HowTo.pdf. At the end of the article, you can find the "How To" for your convenience. In short: once you've added metadata to any of your libraries, the CDC will be automatically generated and stored within your library (limitations apply; please see the How-to below for details).{% endblocktrans %}

{% blocktrans %}A few general points:{% endblocktrans %}

  • {% blocktrans %}Please either select the metadata form via the dropdown menu ("My libraries", mouseover a library, see the dropdown next to the trash icon, go to Advanced, Edit Metadata) or the Metadata entry while browsing within a library.{% endblocktrans %}
  • {% blocktrans %}The metadata form is interactive and will give you feedback. Red means something is still not properly formated or entered, while green is an indication that all is well. Check out the "?" to get more instructions.{% endblocktrans %}
  • {% blocktrans %}Should you have deleted the archive-metadata.md or the Cared-Data-Certificate-HowTo.pdf on purpose or by accident, no problem. You can just copy both files from existing or new libraries. Please keep in mind, should you copy a correctly filled out archive-metadata.md file into another library, the CDC will use that data. So better use a blank file, just to be sure.{% endblocktrans %}
  • {% blocktrans %}The archive-metadata.md can also be edited directly if you prefer that way, but is mainly used to store the metadata itself. We recommend to use the interactive form to add/edit metadata.{% endblocktrans %}

{% blocktrans %}The HowTo:{% endblocktrans %}

{% blocktrans %}The Keeper Service takes care of your data even after a project's end and therefore ensures long term compliant archiving, up to 10 years.{% endblocktrans %}

{% blocktrans %}With storing your data in Keeper and agreeing to the Cared Data Commitment, you gain the Cared Data Certificate for your project. It can act as a proof of long term compliant archiving on your institutional homepage or poster and presentations.{% endblocktrans %}

{% blocktrans %}If you want to gain the Cared Data Certificate you just have to do the following steps:{% endblocktrans %}

  1. {% blocktrans %}Read the Cared Data Commitment https://keeper.mpdl.mpg.de/f/1b0bfceac2/. The Max Planck Digital Library assigns the Cared Data Certificate on a base of trust, so we assume you act in accordance to this commitment once you received the Cared Data Certificate.{% endblocktrans %}
  2. {% blocktrans %}Fill out the archive-metadata.md text file via the interactive form and provide basic metadata for your project. Please follow the recommendations you can find by hovering over "?" in the interactive form.{% endblocktrans %}
  3. {% blocktrans %}Your project must not be empty to receive the Cared Data Certificate.{% endblocktrans %}
  4. {% blocktrans %}Your project must not be encrypted to receive the Cared Data Certificate.{% endblocktrans %}

{% blocktrans %}If you accomplished the before mentioned steps a Cared Data Certificate will automatically be added to your project in Keeper and you will receive a confirmation email.{% endblocktrans %}

{% blocktrans %}Accordingly to the Cared Data Certificate the metadata of your project will be listed in the Keeper project catalogue, which will be (only) accessible within the Max Planck Society.{% endblocktrans %}

{% blocktrans %}The Keeper Team of the Max Planck Digital Library will happily assist you, please contact keeper@mpdl.mpg.de.{% endblocktrans %}
